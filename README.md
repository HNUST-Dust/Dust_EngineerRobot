# Dust_EngineerRobot

## 项目简介

本项目设计并实现了一套龙门架-多自由度机械臂系统，并扩展了远程同构遥操作能力，实现了“视觉感知—位姿估计—轨迹规划—执行控制”闭环。系统集成了机械臂运动学建模、关节级高性能控制、视觉三维感知与抓取、远程姿态同步等多项关键技术，适用于复杂环境下的智能操作与远程协作。

## 系统架构与主要功能

- **机械臂控制侧**
  - 建立正/逆运动学模型，实现关节空间与笛卡尔空间的映射。
  - 关节角度、角速度与力矩建模。
  - 基于 PID + SMC（滑模控制）构建关节级控制器，提升抗扰动能力与跟踪稳定性。

- **视觉感知侧**
  - 基于 Intel RealSense SDK（D435）实现双目深度感知。
  - 目标识别与三维位姿估计，融合机械臂模型实现抓取点规划。
  - 支持多目标连续抓取与轨迹平滑执行。

- **远程同构遥操作**
  - 设计远程同构机械臂控制架构，实现操作端与机器人端的姿态同步。
  - 各关节通过绝对位置磁编码器采集角度，经 RS485 → USB 上传至 PC 控制端。
  - 通过服务器中继，实现远程控制闭环，支持多节点通信与协同。

- **性能指标**
  - 末端定位误差：5 mm
  - 控制响应时间：2 ms
  - 系统端到端延迟：30 ms
  - 状态更新频率：1000 Hz

## 目录结构

- `Algorithm/` 运动学、控制算法、滤波与数学工具
- `App/` 机械臂、底盘、龙门架等应用层逻辑
- `Board/` 板级支持包与硬件配置
- `Communication/` 通信协议与 PC 端通信实现
- `communication_topic/` 通信主题与消息定义
- `daemon_supervisor/` 守护进程与任务管理
- `Device/` 传感器与执行器驱动
- `Drivers/` 底层硬件驱动
- `Platform/` 平台相关接口与适配
- `ThirdParty/` 第三方库与依赖（如 CMSIS、FreeRTOS、HAL 等）

## 快速上手

1. 安装依赖工具链（如 Arm GNU Toolchain、OpenOCD、RealSense SDK 等）。
2. 配置硬件连接，确保各模块正常通信。
3. 编译项目：
   - 使用 CMake 生成工程文件。
   - 编译并烧录固件至目标板。
4. 运行 PC 端视觉与控制程序，连接机械臂与传感器。
5. 通过服务器实现远程遥操作与多节点协同。
